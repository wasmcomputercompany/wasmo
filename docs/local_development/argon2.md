Local Development Argon2
========================

We use the [Argon2] key derivation function to hash customer passwords.

We use the [argon2-jvm] library which requires the host OS has an argon2 package installed.

```bash
$ brew install argon2
```

[Argon2]: https://en.wikipedia.org/wiki/Argon2
[argon2-jvm]: https://github.com/phxql/argon2-jvm#gradle
